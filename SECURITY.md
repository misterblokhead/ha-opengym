# Security

## Reporting a vulnerability

Report it privately through this repository's **Security** tab (**Report a vulnerability**). Please do not open a public issue for it. There is no email address for reports.

## What belongs here

- **The packaging** (this repository: `config.yaml`, `Dockerfile`, `run.sh`, `address.mjs`, `realip.conf`): report it here.
- **openGym itself** (the app, its API, its images): report it to the openGym project, through its [private vulnerability reporting](https://github.com/DuarteSantos8/openGym/security/advisories/new). Not sure which? Report it here and it will be passed on.

## Supported versions

Only the latest release gets fixes.
